TEAM HAIDKIDD - BOTAO PAYLOADS

Substitua jb.html, jb.js e cache.appcache no seu site. Nao altere index.html nem ps4_offsets.js.

Na tela agora existem 3 opcoes: HEN (hen.bin), HaidHEN (haidhen.bin) e Payloads.
A lista mostra os arquivos .bin da pasta payloads/ (diretamente nela), sem a extensao.
Clicar em um arquivo inicia o mecanismo jb.js existente e tenta executar esse .bin.
A URL continua jb.html: a escolha e passada em memoria.

FORMATO DO REPOSITORIO:
- jb.html
- jb.js
- cache.appcache
- hen.bin
- haidhen.bin
- payloads/
  - dumper.bin
  - exemplo.bin

GITHUB PAGES PUBLICO:
Se o site e https://usuario.github.io/repositorio/jb.html, o codigo detecta o repositorio e
consulta a API publica do GitHub ao abrir Payloads. Arquivos novos aparecem sem atualizar jb.html.
A API necessita de conexao com a internet; a API ou o browser podem impor limites.

DOMINIO PROPRIO:
No cabecalho de jb.html configure <meta name="github-repo" content="usuario/repositorio" />.

ALTERNATIVA SEM API:
Crie payloads/index.json com nomes de arquivos (e mantenha atualizado ao adicionar .bin):
["dumper.bin", "exemplo.bin"]
Em servidores Apache/nginx com listagem habilitada, o codigo tenta usar a listagem automaticamente.

IMPORTANTE:
- O site nao pode descobrir arquivos de qualquer pasta estatica por conta propria.
- Cada payload precisa ser compativel com a versao do PS4, o formato esperado pelo jb.js e o estado do jailbreak.
- Os payloads .bin NAO estao incluidos neste ZIP.
- Nao houve teste em PS4; apenas validacoes locais.
